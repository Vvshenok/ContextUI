# Contributing

Report a problem on [GitHub](https://github.com/Vvshenok/ContextUI/issues) with the ContextUI version, target type, input device, expected behavior, and a small reproduction.

Keep proposed changes focused. Preserve the public types, component ownership, and shared input lifecycle. Update the relevant guide and examples when changing the API.
