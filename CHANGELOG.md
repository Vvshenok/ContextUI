# Changelog

## 1.0.0 — 2026-09-08

- Compact context panels for GUI, part, model, attachment, and manual targets.
- Twelve component kinds, live setters, expandable details, custom GUI, and pinning.
- Mouse following, interactive docking, bounded transition grace, and viewport constraints.
- Nine built-in themes, named switching, independent theme copies, and custom overrides.
- Separate button text, section, progress-track, border-thickness, and button-radius tokens.
- Correct GUI inset conversion for surface input and gamepad anchors.
- Focus returns to pinned panels when clicked or selected; outside taps begin dismissal even on processed GUI input.
- Shared input handling, lazy surfaces, owned cleanup, and seven integration examples.
