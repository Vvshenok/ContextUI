# Contributing

Include the ContextUI version, target type, input device, and a small reproduction when reporting a problem.

Keep changes focused and preserve the typed public API. Update examples and documentation when changing behavior. Check affected interactions in Roblox Studio, including cleanup and narrow viewports.

Documentation uses MkDocs Material. The source pages live in `docs/`; navigation is in `mkdocs.yml`. The documentation workflow builds and publishes changes from `main`.
